体系致胜GEO-信源助手 V1.4.16

八平台信源导入 · 提问与完整回答截图 · Excel / Markdown 导出

Windows 已使用验证；Mac 安装入口已准备，等待实机测试。完整功能需要 Chrome 插件和本机服务配合。

Mac 首次安装

  1. 完整解压运行包到长期保存的文件夹，例如“文稿”。
  2. 双击 安装依赖.command，首次联网准备 uv、Python 3.12 和 Mac 依赖。
  3. 双击 启动服务.command，启动后自动打开连接码文件。
  4. 在 Chrome 输入 chrome://extensions，打开“开发者模式”，点击“加载已解压的扩展程序”，选择本文件旁边的 extension 文件夹。
  5. 打开插件侧栏，把连接码粘贴到设置中，点击“保存并连接”。

双击提示没有执行权限时，在终端输入 cd ，把解压后的文件夹拖入终端并回车，再运行 bash ./安装依赖.command 和 bash ./启动服务.command。

Windows 首次安装

  1. 完整解压运行包，双击 安装依赖.cmd。
  2. 完成后双击 启动服务.cmd，自动打开连接码文件。
  3. 在 chrome://extensions 打开“开发者模式”，加载本目录的 extension 文件夹。
  4. 在插件设置里粘贴本机连接码并连接。

当前 Windows 原目录可以继续使用，无需为了 Mac 测试重复安装。不要在同一电脑同时启动多个目录的服务。

文件和服务在哪里

连接码：data/pairing-token.txt。任务、截图和素材：data/tasks/。日志：data/service.log、data/service-error.log。

每台电脑独立生成资料库和连接码。运行包不含原电脑的私人任务、API Key 或虚拟环境。不需要 Codex、CDP 调试、Node.js 或 Homebrew。

Mac 测试重点

  1. 侧栏显示本机已连接，四项运行版本均为 1.4.16。
  2. 豆包、DeepSeek、文心一言、千问、元宝、Kimi、Gemini、ChatGPT 各导入一个带信源的回答。

首次截图按插件和 Chrome 的实际权限提示操作；保持当前 AI 标签页显示，不改变窗口大小。导入、截图和导出无需 API Key。
